OPTIONAL: put the SQLite JDBC driver jar in this folder to store scores in a real database.

1. Download  sqlite-jdbc-3.45.1.0.jar  (any recent version works) from:
   https://repo1.maven.org/maven2/org/xerial/sqlite-jdbc/3.45.1.0/sqlite-jdbc-3.45.1.0.jar
2. Copy the .jar file into this lib folder.
3. Run the game again. The menu footer will say "SQLite database via JDBC".

Without the jar the game still works and saves results to data/matches.tsv instead.
